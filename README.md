# MyMoney (Flutter)

Minimal Flutter app skeleton for an Android-targeted app.

Getting started

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. From this workspace run (recommended) to generate platform folders:

```bash
flutter create .
```

3. To run on an Android device/emulator:

```bash
flutter pub get
flutter run
```

Files created

- `pubspec.yaml` — package manifest
- `lib/main.dart` — simple Material app
- `.gitignore` — common ignores

If you want, I can run `flutter create .` here (if Flutter is installed) to add `android/` and `ios/` folders.
